## Packing list structure by trip type

Build the list from the relevant sections below, adjusted for trip length, season, and group
composition from `01-traveler-profile.md`.

### Beach
- Swimwear, sun protection (SPF <!-- FILL IN: preferred SPF -->), sunglasses, hat
- Light, breathable clothing; one cover-up/evening outfit
- Reef-safe sunscreen if snorkeling is planned
- Kids: swim vests / floaties if young kids per profile

### City
- Comfortable walking shoes (test-worn, not new)
- Weather-layer clothing appropriate to season
- Day bag/crossbody for sightseeing, portable charger
- One smart-casual outfit if dinner reservations are planned

### Nature / hiking
- Weatherproof layers, sturdy footwear
- Daypack, water bottle/filter, basic first-aid kit
- Insect repellent, offline maps downloaded

### Ski
- Thermal base layers, ski jacket/pants (owned or rental-confirmed)
- Goggles, gloves, neck gaiter
- Travel insurance confirmed to cover winter sports (see below)

- [ ] Travel insurance purchased, covering medical, cancellation, and baggage
- [ ] Confirm coverage includes activities planned (e.g. winter sports, water sports) if not
      covered by default
- [ ] Note policy number and emergency contact number in `<DATA_ROOT>/itineraries/<trip-slug>/`

## Vaccination / visa checklist

- [ ] Check destination-specific vaccination recommendations (official health authority site)
- [ ] Confirm visa requirement for the traveler's nationality/nationalities (see
      `01-traveler-profile.md`)
- [ ] Allow processing time for any visa application well before departure

## Pre-departure timeline

| When            | Task                                                              |
| ---------------- | -------------------------------------------------------------------- |
| 8+ weeks before   | Confirm passport validity/visas; check vaccination requirements       |
| 4–6 weeks before  | Book flights/stay if not already; buy travel insurance                |
| 2 weeks before    | Confirm activity bookings, check opening hours for the actual dates   |
| 1 week before     | Check in online where possible, download offline maps, pack list draft |
| 1–2 days before   | Final pack, charge devices, print/save documents offline               |
